# Candlewood Market — Educational Website Project

A responsive, multi-page website concept inspired by publicly available information on Candlewood Market's website.

## Pages
- `index.html` — home
- `menu.html` — interactive category tabs
- `shop.html` — local market categories
- `story.html` — business background
- `gallery.html` — clickable image gallery/lightbox
- `visit.html` — address, hours, map, and demo contact form

## Run locally
Open `index.html` in a browser. No build tools or package installation are required.

## Publish with GitHub Pages
1. Create a new **public** GitHub repository.
2. Upload all files in this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for the Pages URL to appear in Settings → Pages.

## Important assignment note
The exact educational-purpose disclaimer is displayed at the top of every page. Keep it in place when publishing.

## Accuracy and assets
Business information shown here (address, phone, hours, family-owned history, product categories) is based on the public Candlewood Market website and may change. Confirm current details with the business before relying on them. Food and café photographs are illustrative stock imagery from Unsplash, not verified photographs of the actual business. Menu descriptions are illustrative category descriptions, not a confirmed current menu or prices. The sample contact form does not send or store submissions.
